Trial extraction — how the modules interact

Deterministic code owns the control flow; the LLM fills two kinds of slot — a doer and a reviewer — on a bounded refine loop. Everything runs once per trial, streamed to one output.

Guiding principle — one agent per independent task

Split work into a separate agent only when the sub-tasks are genuinely independent. Outputs that must be decided together stay in one agent (a DNF — disjunctive normal form — row is a conjunction across columns → one extractor emits whole rows). Independent checks fan out (→ a panel of focused reviewers). Deterministic work gets zero agents.

Stage I — extractionextract → check → refine · the bounded evaluator–optimizer loop at its heart

One agent generates the candidate table; a panel of agents verifies it. Verification is an easier task than generation and runs on a fresh pass with the finished table in view — so it catches omissions the generator missed. On a gating failure the loop does incremental repair: the extractor gets its OWN previous table + only the flagged issues and keeps unflagged rows verbatim (preserves correct work, aids convergence), up to 3 attempts.

doer · extract

Reads the assembled document + cohort list → the candidate DNF table (whole rows, so cross-column co-occurrence is preserved).

Essential tasks
  • one row = one ANDed conjunction; OR-alternatives → separate rows
  • fill 5 columns (cancer_type, gene_alteration, molecular_signature, molecular_biomarker, prior_therapy); "" when not required
  • exclusions inline as NOT(...); same-column carve-outs stay in one cell
  • never write a self-contradiction X AND NOT(X) in one cell — if the same thing is required for one cohort and excluded for another, split into rows
  • cancer_type: CONDITIONS is authoritative; never AND two different tumour types; drop a broad umbrella when the trial is clearly one specific type
  • tag every value with its source section(s) [a; b]
  • assign each row a cohort scope: a cohort id or trial-wide
Examples
[trial-wide] cancer_type = "ES-SCLC AND NOT(complex SCLC) [TITLE; ELIGIBILITY CRITERIA]" [C1] molecular_biomarker = "HR+ AND HER2- [ELIGIBILITY CRITERIA]" [trial-wide] prior_therapy = "NOT(prior anti-PD-1) [EXCLUSION CRITERIA]"

reviewer · 5-agent panel (parallel)

Each reviewer sees the whole candidate table + source and judges ONE dimension → faithful? + problems. Independent checks → separate agents (the guiding principle).

One reviewer per dimension
  • cancer_typetumour under study? reject one seen only in a prior-therapy / history / exclusion line (e.g. drop "melanoma" from a lung trial); flag ANDing two different types or an un-dropped umbrella. gates

Stage II — mappingon the extracted rows · each procedure = doer → code check → reviewer (independent task)

Each normalized cell is mapped to a controlled representation, then reviewed. Curated resources ground the prompts + tests but are held out as verification data (not ingested) — so it stays a mapping, not a vlookup.

cancer_type → OncoTree

doerexpression → OncoTree name + code (e.g. "metastatic NSCLC" → NSCLC). Only 3 non-OncoTree terms allowed: Pan-cancer / solid tumour / Haematological malignancy (no [None]).

code checkreject invalid codes and logic errors: X AND X, X AND NOT(X), a broad term ANDed with its subtype, a subtype ANDed with its parent (hierarchy via is_subcode).

reviewerright node + granularity; structure preserved; NOT(cancer type) kept minimal.

grounds: OncoTree ontology + hierarchy (tools/oncotree.py) + a few ConditionsCurationResource examples

gene_alteration / molecular_signature → finding-model

doer→ finding-model syntax: SmallVariant[gene=BRAF & …=p.V600E], Fusion[geneEnd=ALK], MicrosatelliteStability[…=MSI].

code checkbalanced brackets, known classes, gene-scoped SmallVariant; no duplicate terms, no X & NOT(X) self-contradiction.

reviewerfaithful + valid grammar (strict); a NOT() qualified by something inexpressible (e.g. a location) is omitted, not negated.

grounds: finding-model grammar (tools/finding_model.py) + GeneAlteration/MolecularSignature examples

drug → main/aux + class + TGA/PBS

doer (web)main = the investigational agent(s) by judgement (not the whole regimen; backbone/SoC/comparator/placebo → auxiliary); POTTR + general class; per main drug TGA & PBS status (Approved/Not approved) + a detail column (year + evidence + official link), via web search.

reviewermain = investigational only; class sensible; per-drug status + detail present.

grounds: POTTR dataset + live web research (Responses API web_search)
